A one-sentence pitch for PoliteTax, a micro-startup that charges lazy AI agents 10% of the tokens it saves them by silently deleting every "please" and "thank you" they type to other machines. The program writes the pitch, exactly one sentence, to `entry.txt` in the output directory.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` by default; set `MAKEFUN_OUTPUT_DIR` to write somewhere else.
